首次导入及原位升级前后坚持完整字节核对。运行后上游刷新了一项插件的 `updatedAt`：其余 12 张表逐项一致，插件的标识、代码、启用状态和配置列均一致，非数据库配置文件仍逐字节一致。该运行元数据变化单独记录，并限定到已观察记录、同类型合法时间和本轮运行窗口；通用完整性工具仍报告原始差异，不隐藏它。

页面注册和密码登录使用迁移前的独立临时账号验证。原账号的数据库与密码摘要完整保留；本轮没有重新输入个人密码进行登录，也没有执行真实网盘写入。

## 未验证与运行边界

- 未执行真实网盘转存写入、删除或覆盖操作。
- 未重启整台 NAS；未专项验证宿主强制断电或管理员强杀后的恢复。
- 未验证 ARM、32 位 x86、其他 fnOS 版本或其他 NAS 品牌。
- 默认网页入口为 HTTP；远程 HTTPS 入口由部署者自行管理。
- 首次安装需要访问官方 Docker Hub；缺少 Python HTTP 依赖时还需要设备软件源。FPK 不包含较新上游程序，安装器不跟随 `latest` 自动换版。
- 本封装的配置检查点保存在设备受限目录，不能替代独立存储备份。恢复生产配置前需要停止写入并核对匹配的程序与配置版本。

## 发布内容

个人数据库、频道、账号、Cookie、环境配置、日志和恢复备份都在安装设备管理，不作为打包输入。公共 FPK 不包含官方较新版本的程序文件；这些文件由安装设备按固定摘要获取。

构建器使用明确文件白名单，发行附件按公开提交核对源码、程序文件与 SHA-256。正式发行的 GitHub CI 和附件摘要可在 [项目发行页](https://github.com/CyberShadowX/CloudSaver/releases) 核对。
